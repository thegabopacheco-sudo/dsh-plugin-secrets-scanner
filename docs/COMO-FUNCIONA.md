# Cómo funciona dsh-plugin-secrets-scanner

Escanea un proyecto local en busca de secretos y credenciales (claves, tokens, passwords, claves privadas) con patrones, enmascarado y excluding de dependencias.

## Arquitectura

```
DSH ──MCP stdio──► server.mjs (bundle single-file)
                    └─ lógica local del plugin
```

## Herramientas reales

- `status`: Estado
- `patterns`: Patrones
- `scan`: Escanear secretos

## Seguridad

- Lectura por defecto; acciones con `confirm:true`.
- Modo `read-only` por variable de entorno.
- Listas blancas cuando aplique.
- Auditoría en `<DSH_HOME>\cache\secrets-scanner\audit.jsonl`.
- Rate limit de acciones.

## Verificación

Tests end-to-end con el cliente MCP oficial (`@modelcontextprotocol/client@2.2.0`)
y artefacto empaquetado (`npm pack` → `postinstall` → servidor desplegado).
